# Really Bad Design Museum

A playful, interactive museum of thirty-seven terrible website ideas. Built with plain HTML, CSS, and JavaScript, with no runtime dependencies.

The browser has one entry point, `app.js`, which handles routing, page chrome, and difficulty progression only. It calls into a single exhibit registry, `exhibits/registry.js`, which owns the validated, ordered catalog of all 37 exhibits and dispatches rendering. Exhibit implementations live in `exhibits/`, grouped by what they actually do rather than by when they were added: `forms-and-inputs.js` (text/dropdown/dial/puzzle-style controls), `interaction-and-simulation.js` (physical, timed, or game-like demos), `content-and-navigation.js` (reading and wayfinding exhibits), and `commerce-and-messaging.js` (marketing copy, checkout, and subscription flows). `website-behavior.js` contains the destructive registration-validation exhibit. Each module exports its own exhibit records (metadata, preview markup, and a render function); `exhibits/shared.js` holds the small rendering helpers those modules share. Checkout-specific styles live in `exhibits/marketing.css`, imported by `exhibits.css`.

## Run locally

Requires Node.js 18 or later.

```sh
npm start
```

Open **http://localhost:3000**. Set `PORT` to use a different port.

The site deploys to Cloudflare Workers with `npm run build` followed by `npm run deploy`. The build creates `dist/` with the browser assets, 37 per-exhibit share pages, and 38 social-preview images. Clean URLs such as `/exhibit/cat-captcha` contain their own title, description, canonical URL, and 1200×630 Open Graph/Twitter artwork; the Worker injects the active workers.dev or custom-domain origin. Legacy hash exhibit URLs open normally and upgrade to their clean shareable route in the browser. Google Fonts is optional; local font fallbacks are included.

### Generate share thumbnails

The committed exhibit thumbnails in `share/` are rendered from the gallery's real HTML/CSS previews. Install Chromium once with `npx playwright install chromium`, run the museum with `npm start`, then use a second terminal:

```sh
npm run generate:share
```

The generator renders and validates one numberless 1200×630 PNG per exhibit. It fails if a preview is missing, text overflows, an exhibit number leaks into the artwork, or `share/` contains missing or stale exhibit images. Pass a different running origin with `npm run generate:share -- --url http://127.0.0.1:3019`.

Use `npm run generate:share -- --older` to regenerate only exhibits without the **New** badge, or `npm run generate:share -- --ids runaway,phone` for specific exhibits. Both selections verify that the excluded images and `museum.png` remain byte-for-byte unchanged. All 32 older previews use responsive compositions with larger artwork for social images.

Use `npm run generate:share -- --check` to run the same export and validation into a temporary directory without modifying committed images. This also supports `--url`, `--older`, and `--ids`; the output directory is printed for inspection. Export waits for fonts and embedded images, disables animations and transitions, and rejects active animations or mobile scroll-activation state. Share PNGs use the static composition, not a hover or scroll-animation frame. Check-only mode validates exportability, not whether committed PNGs match the latest exhibit copy.

Thumbnail tone: show the absurd task and its consequence, with the joke aimed at the interface, not the visitor. Keep the exhibit recognizable, the punchline brief, and fictional money or subscriptions clearly fictional. Strong existing visual jokes do not need replacing just to make the collection uniform.

### Check thumbnails

With the museum running and Chromium installed, run `npm run test:thumbnails`. Set `MUSEUM_URL` to test another origin. The check covers all 32 older previews at 1440, 768, 390, and 320 pixels, including internal text clipping, artwork bounds, spacing below exhibit numbers, and Runaway caption overlap. It also loads all 32 older share images and checks their dimensions. Gallery/share contact sheets and mobile close-ups are saved to `/tmp/museum-thumbnails` for visual review.

Thirty-five previews replay a short animation on hover or keyboard focus. The original fourteen are Runaway, Phone Casino, Cookie Switchboard, Seismic Editor, Alphabet Shuffle, Windswept Volume, Volume Seesaw, Password Crane, Physics Cart, Notification Fly Swatter, Loading Experience, Checkbox Ecosystem, Shrinking Unsubscribe, and Tetris Volume.

Twelve more use brief setup-and-punchline sequences: Self-Correcting Search changes the query before stamping it; Expanding Form types Alex while the next field retreats; Corporate Fog Machine completes its checks before revealing more setup; Password Gym introduces the apology rule after ordinary checks; Elevator Date counts down toward the birthday; Email Auction raises the bid and briefly stamps the still-needed @ SOLD; Dropdown Word Processor opens and selects its final character; Terms & Conditions ticks the checkbox before revealing an exam; Font Buffet's initially consistent lettering adopts competing styles; Retro Homepage reverses Alex; Address Jigsaw lifts a piece toward its gap before returning it; and AI Everything Store scans a spoon that still requires calibration. These additions last 1.1–1.4 seconds and settle on the existing static compositions.

The final nine additions are Radio Receiver tuning into H; CAT-PCHA's short grid chase; Mystery Meat Menu repeating its unhelpful tooltip; Recipe Odyssey interrupting toast with a quiz; Layout Earthquake expanding an ad and displacing the link; Hover Dependency missing the menu bridge; Validation Afterthought rejecting and striking out answers; Scroll-Through Modal moving background text behind a stationary dialog; and Unix Birthday Picker converting a familiar date into milliseconds. These sequences last 1.3–1.7 seconds. Cancellation stays static to preserve time to read its double negatives.

Replays run once per interaction, preserve the card layout, and are disabled for reduced motion. Their static compositions carry the same joke in share images. The thumbnail test checks all 35 previews with hover and focus at 1440, 768, and 320 pixels, six sampled animation poses, text-substitution and reveal states, stationary modal/cursor geometry, and reduced-motion behavior, including a live preference change. Midpoint screenshots are included with the gallery screenshots. The mobile suite also verifies scroll activation and completion for the twelve setup-and-punchline sequences and the final nine additions, plus stale-hover suppression for the four New previews.

During touch input, a preview plays when its artwork center rests 30–45% down the visible viewport for 180 ms after scrolling settles and the finger is released. Touch-only devices start in this mode; hybrid tablets switch to it when a touch or pen gesture begins, suppressing stale cursor-hover playback. Mouse movement or wheel/trackpad input cancels scroll playback and restores cursor mode, even if the device still reports a coarse primary pointer. Keyboard-focused previews pause the scroll queue. The card nearest the one-third mark plays first; only one scroll replay runs at a time, once per card per collection visit, including across category filters. Scrolling again cancels the replay rather than playing it offscreen. Reduced motion and hidden tabs stop playback, and leaving the collection removes its listeners and pending work. This is visual activation only: browser focus does not move and taps still open exhibits immediately. Run `npm run test:thumbnails:mobile` (with `MUSEUM_URL` for another origin) to check activation timing, swipe/hold behavior, tablet sequencing and input switching, filtering, navigation, visibility, focus preservation, and reduced motion.

### Difficulty links

Add `?mode=hard` to any exhibit URL to open it directly in hard mode, for example `/exhibit/runaway?mode=hard`. Use `?mode=fixed` for Fix it; omitted, `easy`, or unrecognized modes open easy mode. Switching difficulty—including automatic progression—updates the current URL without adding browser-history entries, so copying or refreshing the address preserves the selected mode. The toolbar Reset returns to easy and removes the mode parameter. Next exhibit links still start the next exhibit in easy mode.

## The collection

- The CAT-PCHA (`/exhibit/cat-captcha`): prove you are human by being a mouse. Collect four cheeses and reach the mouse hole while a cat follows the shortest route toward you after every move. Worse mode starts with six cheeses, gives the cat two steps every eighth turn, and rejects your first completed exit attempt. A seventh cheese appears at the top left as a processing fee, and the exit relocates to the top right. Cheese pickups distract the Worse-mode cat for one turn, including sprint turns; both modes remain winnable. Getting caught means restarting verification, not the whole museum. Arrow keys, WASD, direction buttons, and tapping adjacent squares all work. The chase is turn-based, and reduced motion removes movement transitions. Fixed mode replaces the game with a demo checkbox and confirmation. Neither mode performs a real security check.
- The Runaway Button (`/exhibit/runaway`): flees to randomized, distant positions across an arena. Touch cannot hover, so the button relocates on its own timer, dodges near-miss taps, and evades a dragged finger. Each round draws a hidden direct-hit requirement: 6–12 hits in easy mode (median 8), or 18–24 in worse mode (median 20). Offsets from the median have weights `2, 2, 4, 2, 2, 1, 1` for `-2` through `+4`; near misses and timed moves do not count. Earlier direct hits trigger a flinch; the final required hit immediately turns the page green, stops the game, and reports the difficulty, direct hits, and total escapes. Worse mode also detects approaching cursors, shrinks the target, leaves clickable decoys, and relocates faster on touch. Reset draws a fresh requirement. Keyboard, reduced motion, and Fix it bypass the hit requirement and report the corresponding catch method.
- The Password Gym (`/exhibit/password-gym`): satisfy 20 progressively revealed rules, including a digit sum, weather reference, apology, color, and year. Rules advance automatically as you type or paste, with all earlier requirements still enforced and no submit clicks. The default is solvable. Worse mode expands to 32 rules and is deliberately impossible: its final rule forbids digits while earlier rules require them. The contradiction is explained when reached. Fixed mode checks one visible length requirement automatically. **Never enter a real password or reuse a puzzle solution for an account.** This is not a strength evaluator.
- The Self-Correcting Search Bar (`/exhibit/correcting-search`): paused typing replaces words with close spellings from a 749-word vocabulary of animals, food, household objects, fantasy creatures, office terms, places, absurd real dictionary words, and other questionable alternatives. It chooses a random replaceable starting point among the first ten words, then rotates across those words instead of exhausting one cluster first. The replacement is highlighted with an “OFFICIAL CORRECTION” stamp. Matching uses edit distance with adjacent transpositions and allows one edit for short words, two for five-letter words, or three for longer words. A small stemmer runs alongside it, so an inflected query is matched on its base word and answered in the same form: `searching` becomes `starching`, `tickets` becomes `thickets`, and `matched` becomes `marched`. Only verbs answer `-ing` and `-ed` queries and only adjectives answer `-er`, `-est`, and `-ly` queries, so replacements stay real words rather than invented ones. Case, punctuation, and surrounding text are preserved. Reject up to three suggestions (five plus short explanations in worse mode) to search the original query. Unmatched words stay unchanged and remain searchable. There is no large dictionary payload, download, or external search service. Fixed mode searches the entered query directly.
- The Layout Earthquake (`/exhibit/layout-earthquake`): find the library story below two earlier stories, outside the initial newspaper viewport. Its first two click, tap, or keyboard activations insert a sponsored block at the link's position, pushing the link down without opening the article; the third opens it. Worse mode buries it below four stories and intercepts four attempts with larger blocks before allowing the fifth. Blocks can be dismissed without resetting the attempt count; museum Reset restarts it. Pointer entry, touch, keyboard focus, or scrolling starts loading automatically; Load live edition is optional. Easy mode continuously cycles expanding and collapsing ads every 1.8 seconds. Worse mode updates every 1.1 seconds, doubles headline placements from three to six, adds breaking-news, newsletter, and related-story blocks throughout the article, and changes column widths. Timed ads can reach 380 pixels tall and return after dismissal in hard mode; easy mode respects dismissal. Updates continue during reading until completion, pause, or leaving, and suspend in hidden tabs. Reduced motion uses manual timed updates but retains activation-triggered blocks. Fixed mode puts the library first, opens it immediately, reserves ad space even after dismissal, and finishes loading after six updates. The outer exhibit stays stable; no bookmark is stored. The local photograph and source are listed in `assets/README.md`.
- The Scroll-Through Modal (`/exhibit/scroll-modal`): scroll down a fictional checkout to Choose delivery, followed by explanatory text and a customer-care footer. Easy mode sends delivery-dialog scrolling into the checkout underneath. Both easy and hard offer Fastest delivery in two days for $5,000, just one day faster than the free three-day option labeled "I'm OK waiting an extra day". Easy puts those choices in the delivery dialog. Hard requires opening Choose shipping speed from the bottom of that dialog and confirming a choice in a third modal. Closing or escaping without confirming discards the draft choice. Each new gesture randomly chooses one, two, or all three layers and an independent forward or reverse direction for each: 26 non-empty combinations. Wheel events within 250 milliseconds keep the same targets; touch drags and held keys keep theirs until the next gesture. Closing the speed chooser restores the delivery dialog, and subsequent gestures target only the two remaining layers. Native scrollbars and labeled vertical controls remain reliable. Pushing past a scroll area's boundary produces an elastic bounce without technical status text; reduced motion disables it. Close, Escape, view changes, and leaving cancel animations. Confirmed delivery selections and scroll position survive reopening the speed chooser. Fixed mode uses one delivery dialog with normal scrolling and a stationary background. Museum controls stay outside the overlays. No order or payment exists.
- The Validation Afterthought (`/exhibit/validation-afterthought`): register for a fictional open house using four fields. A failed submission reveals only the first unmet formatting rule and clears all other answers. Worse mode omits the field name from the error banner. Fixed mode shows requirements up front, validates inline, and preserves input. All modes accept the same reachable solution. Replaces Calendar Treadmill with a new URL. Use invented details; nothing is submitted or stored.
- The Hover Dependency (`/exhibit/hover-menu`): find the Pivot desk lamp through nested shop menus connected by six-pixel-wide safe pointer corridors. Easy mode uses a 56-pixel-long straight bridge, a 55-millisecond off-path allowance, and a 2.8-second mouse timeout. Worse mode adds a submenu and 64-pixel-tall twisting paths, with 45-millisecond departure and 2.2-second expiration delays. Touch deadlines shrink with each submenu: 650, 550, and 450 milliseconds in easy mode; 420, 350, 280, and 210 milliseconds in hard mode. Each selection renews the deadline for the deepest open submenu, but holding a finger down does not pause it. No finger tracing is required. Keyboard navigation stays open without a deadline. Hold menu open appears after two failed tries (timeout, leaving the path, or choosing a wrong department) and bypasses the timing when checked. Close and Escape do not count; reset and difficulty changes restart the count. Reduced motion enables the bypass automatically even while the control is hidden. Fixed mode uses persistent click-open menus without the unnecessary hold control. Timers stop on cleanup and pause while the tab is hidden.
- The Notification Fly Swatter (`/exhibit/notification-swatter`): the first keystroke or paste automatically starts in-page alerts. Complete six fields (name, email, organization, subject, message, and the code QUIET), then swat the remaining notifications. Pause continues to hold the swarm while editing. Alerts cover the scrollable form but never the outside Pause and Swat one controls. Worse mode spawns faster and creates alerts for misses. Keyboard, touch, and reduced-motion alternatives are available; completion or leaving the exhibit stops the swarm. Fixed mode has no alerts. No browser notification permissions are requested.
- The Tetris Volume Control (`/exhibit/tetris-volume`): move, rotate, and drop tetrominoes across a 10-by-12 board. Every settled cell controls a pretend volume slider, with 80 cells—two-thirds of the board—representing 100%. Completed rows disappear and lower the volume with them. Another block replaces only the falling piece. Arrow keys move/lower blocks; Up or R rotates with either the board or a game button focused. Space drops on the board and activates focused buttons normally. The game pauses on demand, window blur, or tab hiding; reduced motion uses manual drops. Worse mode accelerates gravity. Empty speaker resets a jammed stack; fixed mode uses a normal slider. No audio plays and device volume never changes.
- The Phone Number Casino (`/exhibit/phone`): roll and lock ten digits to enter the fictional number 2025550107. Worse mode also rerolls and unlocks the digit to the left, rewarding a right-to-left strategy.
- Terms & Conditions: The Game (`/exhibit/terms-game`): an 80-clause fictional agreement must be scrolled to the end before an eight-question, open-book reading exam unlocks. Answers are buried in the document and must be correct before acceptance becomes available. Worse mode doubles the document to 160 clauses, asks twelve questions, and hides the answer's clause reference unless you spend one of five hints. A wrong answer restarts and reshuffles the exam without refunding hints; previously revealed references remain available when those questions reappear. Declining is always available. Fixed mode offers a short summary with immediate accept/decline choices. No real agreement is created.
- The Font Buffet (`/exhibit/fonts`): edit a sentence whose words receive random fonts, sizes, colors, and rotations. Worse mode styles each character separately. "Make fonts agree" remixes them instead; fixed mode uses consistent typography.
- The Unix Birthday Picker (`/exhibit/unix-birthday`): slide through Unix timestamps in **milliseconds**, with a live UTC date/time preview and one-hour keyboard steps. A small Align to UTC midnight button snaps to the start of the selected UTC date before confirmation. Dates from January 1, 1900 through today are supported, including negative timestamps. Worse mode is a single manual timestamp field with live UTC date/time conversion and automatic birthday validation, without retyping, timezone selection, a confirmation button, or an alignment helper. The preview also converts representable timestamps outside the birthday range while validation explains why they cannot be accepted. Fixed mode uses a native date field.
- The Cancellation Labyrinth (`/exhibit/cancel`): navigate four double-negative confirmations to cancel a fictional subscription. Worse mode adds two checkpoints, shuffles button positions, and resets progress on a wrong answer.
- The Recipe Odyssey (`/exhibit/recipe`): six mandatory reading-comprehension quizzes stand between you and toast. The fake skip button detours to an ad. Worse mode resets reading progress after wrong answers or attempts to skip.
- The Expanding Form (`/exhibit/expanding-form`): a conventional contact form with name, email, subject, and message fields. Extra spacing grows exponentially as `32 * (2^(characters/5) - 1)` pixels per field, capped at 60,000 pixels. The final Message field sends the submit button even farther away: `128 * (2^(characters/3) - 1)`, capped at 360,000 pixels. Worse mode reduces the exponent scales to three and two characters respectively, triples both caps, and adds folding effects. Compress temporarily removes gaps without losing answers; typing expands them again. The viewport stays bounded, reduced motion removes folding/animation, and fixed mode keeps stable spacing.
- The Radio Text Receiver (`/exhibit/dropdown`): tune a 0–9999 Hz slider to receive one character at its exact station frequency. Anything between stations is static. A non-clickable directory lists A–Z, space, and punctuation; the dial resets after each reception. Normal mode keeps stations stable. Worse mode reassigns every station and changes frequency offsets after each character. Undo removes the last character, and fixed mode restores a normal text box. The original URL is preserved.
- The Seismic Text Editor (`/exhibit/seismic-editor`): every edit shakes the exhibit and increases the chance that the whole sentence tumbles into a pile of letter tiles. Slow typing produces gentle tremors, rapid edits amplify them, and newly entered punctuation adds a jolt, with extra force for exclamation marks. Pausing for 800 milliseconds returns the next edit to the gentle baseline. Pasting adds stress for each added character; reaching 100% stress guarantees a collapse. A collapse pauses editing but preserves the exact input, and Rebuild restores the letters and resets stress and typing cadence. Worse mode builds stress twice as fast and shakes harder. Fixed mode removes shaking and collapse risk. Reduced-motion preferences disable both animations, and the museum's controls never move.
- The Volume Seesaw (`/exhibit/volume-seesaw`): add pebbles, bricks, and anvils to either end of a wobbling beam. Its angle drives a silent volume slider; hold the setting to freeze it, or remove weights and rebalance. Worse mode adds buoyant balloons and rolls a weight to the opposite side every third addition. Reduced motion settles instantly, and leaving the tab pauses active wobbling. Fixed mode uses a normal slider. No audio plays or device volume changes.
- The Windswept Volume Slider (`/exhibit/wind-volume`): drag a vertical slider through gusts that twist its track and shove the simulated volume around. Pointer movement is projected onto the rotating track, so up stops reliably meaning louder. Letting go releases the handle, but the wind keeps moving the value until Save shelters it at 35-39% (the target is 37%). Worse mode brings stronger gusts and possible upside-down controls. Keyboard controls work too; reduced motion freezes the track but retains numeric wind interference. Fixed mode provides a stable, predictable slider. No audio plays, no audio APIs are used, and device volume never changes.
- The Checkbox Ecosystem (`/exhibit/checkbox-ecosystem`): checked preferences need feeding before their health runs out and they uncheck themselves. Neglected cards wander inside the habitat. Configure three requested settings, keep the other boxes off, and save to stop the ecosystem. Worse mode decays faster and creates checked offspring every third feeding, up to twelve preferences. Pausing holds the habitat, reduced motion stops wandering, and fixed mode offers stable independent checkboxes. Only local demo preferences change.
- The Password Crane Game (`/exhibit/password-crane`): steer a claw across all 128 ASCII characters in 16 banks of eight hoppers, plus a drop chute. Assemble the visible fictional password `Claw_M00n!42`, or experiment with up to 80 characters. Control characters have named tiles and appear as tokens such as `[NUL]` and `[TAB]` in the output; each represents one actual character. Arrow keys steer, Page Up/Down change banks, Home/End jump to the first hopper/chute, and Space operates the claw with the cabinet focused. Held tiles survive bank changes. Worse mode grabs the next ASCII character every third attempt. Return tiles, undo, or reset to recover. Fixed mode uses a normal invented-phrase field. Never use real credentials.
- The Physics Shopping Cart (`/exhibit/physics-cart`): adding the first fictional product immediately starts a wheeled cart rolling downhill. More weight means more cartoon acceleration toward a pretend Buy now zone. Brake, pull back, pause, or return to the start without losing your basket. Pausing continues to hold the cart while you edit items. Worse mode adds a steeper slope and a speed bump at 50% that launches and tilts the cart while cutting its speed by more than half. Reduced motion keeps the slowdown and BUMP status but omits the jump, using manual half-second steps instead of automatic rolling. Fixed mode uses a stationary basket and an explicit simulated checkout. There are no real purchases or payments.
- The Email Address Auction (`/exhibit/email-auction`): opens directly onto a catalog of all 94 non-space printable ASCII characters, without requesting an email first. Browse/filter lowercase letters, uppercase letters, digits, and punctuation; bid for 1-20 copies at a time and rebuy characters as needed. Vowels attract competition and `@` has a reserve price. Won copies go into a tray: assemble any valid email up to 254 characters, return mistakes, or drag characters to reorder them. Only winning bids spend imaginary coins. Worse mode raises prices and competition. Restart a lot without losing winnings, or reset the full auction. Fixed mode uses a normal email field. No storage, email, money, or external requests are involved.
- The Elevator Date Picker (`/exhibit/elevator-date`): ride between year floors, then transfer to separate month and day elevators. - The Shrinking Unsubscribe Button (`/exhibit/shrinking-unsubscribe`): starts with an explicitly fictional subscription. Approaching the cancellation button with a mouse makes it shrink until it relocates to a distant position. Touch has nothing to approach, so the button shrinks on a timer, relocates once it reaches its minimum, treats a near-miss tap or a dragged finger as a threat, and squirms out of a clean tap by collapsing to nothing under your finger and reappearing elsewhere, as though the tap never happened. Every escape also brings the button back slightly smaller, down to a floor of 55%. Both evasions are bounded: the nerve to squirm away decays with every direct hit and is exhausted after eight, and after eight close mouse approaches retention gives up and holds still, so the exhibit is always completable with either input. Worse mode shrinks sooner, shrinks smaller, relocates earlier, runs the touch timer almost twice as fast, and squirms away more stubbornly. Cancellation changes only the local demo state; no real account, subscription, or payment exists.

- The Mystery Meat Menu (`/exhibit/mystery-menu`): find and acknowledge a shipping policy, then retrieve a fictional receipt through six unlabeled symbols with useless tooltips. Worse mode reshuffles the icon mappings after every navigation click. Fixed mode supplies stable, descriptive labels.
- The Alphabet Shuffle (`/exhibit/alphabet`): a separate character-entry slider with a randomly ordered alphabet that reshuffles after every appended character. Worse mode also reshuffles on committed slider adjustments. The visible preview always shows the character that will be appended.
- The Corporate Fog Machine (`/exhibit/corporate`): mandatory onboarding adds more steps every time you complete one. Going back discards your progress.

Hard mode repeatedly rearranges recommendations and the order summary before settling. Fixed mode reserves space and keeps checkout stable. Every exhibit has original, worse, and fixed modes, a reset button, a curator's note, and a persistent mode toolbar. Worse mode displays a highlighted summary of exactly what it adds to the original version. Use **Escape** to return to the collection. Filter the collection by category or navigate directly to an exhibit, such as `/exhibit/runaway`.

Interactions are local and ephemeral. Messages, guestbook entries, and purchases are simulations; no data is submitted or stored. These are deliberately frustrating task interfaces, not just visual parodies. The museum's sticky Exit, Reset, and Fix it controls remain trustworthy. Fixed mode removes the obstacles rather than merely restyling them.

There are no flashing effects or browser traps. The runaway button remains usable by keyboard and touch and respects reduced-motion preferences. All other tasks can also be operated with a keyboard. The character dial supports arrow keys and one-unit adjustment buttons.

Every exhibit highlights its Easy/Hard difficulty controls. Completing an easy task shows a translucent full-screen overlay with a three-second countdown before automatically starting hard mode. “Stay here” dismisses it and keeps the current result instead. The overlay disappears when hard mode starts; reduced-motion preferences disable its animations. Hard and Fix it completions never advance automatically. The toolbar Reset, manual mode changes, and leaving the exhibit cancel any pending transition. The Runaway Button retains its green victory screen behind the overlay during this pause.

Renderers signal success with an explicit `exhibit-complete` event on their stage; the shared page controller handles the one-shot transition and cleanup. Invalid answers and intermediate steps do not trigger it. For the deliberately endless Corporate Fog Machine, finishing the original four onboarding steps is the milestone—management rewards you with harder onboarding.
